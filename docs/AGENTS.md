# 智能体说明

## 概述

## 使用建议

1. **根据场景选择**: 不同的写作场景选择对应的专业智能体
2. **明确需求**: 在主题描述中详细说明你的写作要求
3. **调整参数**: 
   - 字数: 根据实际需要设置
   - 温度: 0.3-0.5更严谨，0.7-0.9更有创意
4. **风格要求**: 可以补充具体的风格偏好
5. **多次尝试**: 如果第一次结果不理想，可以调整参数重新生成
