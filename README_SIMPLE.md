# AI写作智能体平台 - 纯前端展示版

## 简介
这是一个简化的纯前端展示版本，展示AI写作智能体的组织架构。

## 特点
- ✅ 纯前端，无需后端
- ✅ 展示智能体组织架构
- ✅ 包含标题智能体（点击直接跳转到腾讯元器）
- ✅ 简洁美观的UI设计

## 启动方式

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问
浏览器会自动打开，或手动访问 http://localhost:5173

## 功能说明

### 智能体架构
展示4个部门的智能体：
- 👑 **人格化引擎** - 人设部门
- 📚 **智慧中枢** - 知识部门
- 🏭 **创作工厂** - 内容部门（包含💡标题智能体）
- 🧠 **决策大脑** - 数据部门

### 标题智能体
点击"创作工厂"中的💡标题智能体，会直接跳转到腾讯元器的标题生成页面。

## 技术栈
- React 18
- TypeScript
- Vite
- Ant Design
- 纯静态展示（无后端依赖）

## 注意事项
- 这是一个演示版本，所有功能都是展示性质
- 点击智能体后，除了标题智能体外，其他都只是显示信息
- 无需后端服务，直接运行前端即可
