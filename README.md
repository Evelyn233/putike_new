# AI写作智能体平台

一个展示AI写作智能体组织架构的纯前端应用。

## 在线访问
部署在 Vercel 上，访问链接将在部署后提供。

## 功能特点
- 💡 展示智能体组织架构
- 🏭 集成标题生成智能体
- 🎨 精美的UI设计
- 📱 响应式布局

## 本地运行

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 技术栈
- React 18
- TypeScript
- Vite
- Ant Design

## 部署
使用 Vercel 部署，一键部署到云端。
